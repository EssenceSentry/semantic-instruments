# Browser-trained image example

Import `image-toy-model.silab` through the laboratory's dataset menu. It contains 24 selected non-graphic thumbnails, real browser-computed SigLIP vectors, fixture labels from the supplied weapons annotations, and a logistic probe fitted in WebAssembly.

This is the exported example used in the verification record: 20 fitting rows, 4 held-out rows. It is a small teaching dataset, not a model-performance benchmark. The portable packager includes it without needing to rerun browser QA.
